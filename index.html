Board Setup & Code Export

Choose your microcontroller. The generated sketch uses an SSD1306 I²C OLED (usually address 0x3C). Check your board and OLED module before wiring.

Wire connections

Connect GND to GND and VCC to the voltage supported by your OLED module. Do not assume every module is 5V tolerant.

Install the “Adafruit SSD1306” and “Adafruit GFX Library” libraries in Arduino IDE. Board pin labels can vary by model.
